Manage CIDRs
{% if iran_cidr_source == "static" %}
The "static" provider treats CountryNetwork rows themselves as the source of truth - no external feed is fetched. Monthly validation (1st of each month) re-verifies them against themselves. Add real, trusted CIDR data via Iran → CIDRs, or set IRAN_CIDR_SOURCE=ripencc to fetch from RIPE NCC's own delegated stats instead.
{% elif iran_cidr_source == "ripencc" %}
The "ripencc" provider fetches RIPE NCC's own delegated-extended stats file (the registry's primary allocation record, no API key required) and extracts every IPv4/IPv6 block currently allocated or assigned to Iran. Monthly validation (1st of each month) re-fetches it, disables any CIDR it no longer reports, and re-checks every IP currently flagged Iranian.
